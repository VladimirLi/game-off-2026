# Body Hop: tester guide

Copy everything below the line into a message to a tester. The link has `?playtest=1`, so the game marks the
tester's anonymous play stats as a playtest in PostHog (project "Body Hop"); nothing else is needed from them.

---

Hi! I'm making a small puzzle game for a game jam and nobody has played it yet. Could you give it 15–30 minutes?

**Play it here:** https://vladimirli.github.io/game-off-2026/?playtest=1

- A computer (Chrome or Firefox) or a phone both work.
- Please don't ask me anything while you play. Being confused is useful information.
- Stop whenever you're bored or stuck. Quitting is useful information too.
- The game records anonymous play stats (which levels you finish, how many moves, where you stop) so I can see what's hard. No name, no cookies.

**When you're done, tell me in one line how it felt.** Examples: "fun but level 7 was too hard", "didn't get what the cat does until level 4", "got bored at level 9". You can also leave a note inside the game: pause menu (Esc, or MENU on a phone) → **Send feedback**.

Optional: anything that looked broken, or that you liked.

Thanks!
